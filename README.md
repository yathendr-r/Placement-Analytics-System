# Placement Analytics System

## Overview
Analyzed real placement data of 401 students across 16 streams to identify key factors affecting student placements.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, MySQL, Power BI, Excel

## Key Findings
- Overall Placement Rate: 71.32%
- Innovative Projects: 86.8% placed vs 57.3% without
- Technical Courses: 81.1% placed vs 62.0% without
- Backlog Impact: Only 40.3% placed vs 77.5% without
- Internship Impact: 75.4% placed vs 67.8% without

## Project Structure
- eda_analysis.py — Python EDA and 12-chart dashboard
- sql_queries.sql — 12 SQL queries (basic to advanced)
- placement_dashboard.png — 12-chart visual dashboard
- Placement_Analytics_Dashboard.pdf — Power BI dashboard
